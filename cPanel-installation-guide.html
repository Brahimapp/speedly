Speedly - cPanel Installation Guide

Prerequisites

  • cPanel hosting account access
  • Node.js 18.0 or higher (contact your hosting provider if not installed)
  • npm 8.0 or higher

Installation Steps

1. Build the Application

  1. Run the build command locally: 
    npm run build
  2. This will create a dist directory with the built files

2. Upload to cPanel

  1. Log into your cPanel account
  2. Navigate to File Manager in cPanel
  3. Go to the public_html directory (or your desired subdirectory)
  4. Upload all contents from the dist directory

3. Configure .htaccess

  1. Create or edit the .htaccess file in your website root directory
  2. Add the following configuration: 
    <IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteCond %{REQUEST_FILENAME} !-l
  RewriteRule . /index.html [L]
</IfModule>
Important Notes:
  • Ensure proper HTTPS configuration on your domain
  • Configure environment variables in cPanel if required
  • Set appropriate file permissions (usually 644 for files and 755 for directories)

Troubleshooting

  • If you see a blank page, check the browser console for errors
  • Verify that all files were uploaded correctly
  • Ensure .htaccess file is properly configured
  • Check server error logs in cPanel
